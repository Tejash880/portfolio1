Problem

Manual grading of descriptive answers is time-consuming, inconsistent, and doesn't scale. Teachers need a reliable, automated system that understands context — not just keyword matching.

Approach

Built a multi-signal AI pipeline combining Universal Sentence Encoder for deep semantic similarity, TF-IDF cosine for lexical overlap, Jaccard index for keyword matching, edit distance for structural similarity, and NLI-DeBERTa for contradiction detection — with automated PDF extraction for bulk submissions.

Result

A scalable role-based academic platform with teacher/student portals, classroom management with invite codes, section-based assignments with deadlines, batch grading with real-time SSE streaming, analytics dashboards with leaderboards, and intelligent scoring workflows.
