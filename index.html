★ Featured Project

AutoGrade

AI-Powered Descriptive Answer Evaluation System

Problem

Manual grading of descriptive answers is time-consuming, inconsistent, and doesn't scale. Teachers need a reliable, automated system that understands context — not just keyword matching.

Approach

Built an AI pipeline combining Universal Sentence Encoder for semantic similarity, TF-IDF for lexical overlap, and Natural Language Inference for contradiction detection. Automated PDF extraction handles bulk submissions.

Result

A scalable role-based academic platform with teacher/student portals, classroom management, automated submissions, and intelligent grading workflows — reducing manual grading effort significantly.
